# Machine Learning and Deep Learning Workspace

This repository contains Jupyter notebooks and scripts for learning and experimenting with NumPy, PyTorch, and basic machine learning and deep learning workflows.

## Project Structure

```
classification_dl2.ipynb
computervision_dl3.ipynb

    01_pytorch_workflow_model_1.pth
```

## Notebooks

- **ml_numpy.ipynb**: NumPy basics, array operations, and data manipulation.
- **fundamentals_dl0.ipynb**, **fundamentals_dl1.ipynb**: PyTorch basics, tensors, and simple neural networks.
- **classification_dl2.ipynb**: Deep learning classification examples.
- **computervision_dl3.ipynb**: Computer vision tasks using PyTorch and FashionMNIST.

## Scripts

- **helper_functions.py**: Utility functions for plotting, accuracy calculation, and model evaluation.

## Data

- **data/**: Contains datasets used in the notebooks (e.g., FashionMNIST).
- **images/**: Example images for NumPy image processing.
- **models/**: Saved PyTorch model weights.

## Getting Started

1. Install dependencies:
   ```sh
   pip install numpy torch torchvision matplotlib pandas
   ```
2. Open notebooks (`.ipynb` files) in Jupyter or Visual Studio Code and run the cells.
